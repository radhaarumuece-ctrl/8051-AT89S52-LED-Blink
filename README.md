
# 8051 AT89S52 Bare-Metal Programming

## Objective
LED Blink using AT89S52 microcontroller.

## Hardware
- MCU: AT89S52
- CPU Core: 8051
- Operating Voltage: 5V
- Programmer: USB ISP
- IDE: Keil uVision

## GPIO Configuration
- LED Port: P1
- LED Pin: P1.0

## Software
- Keil C51
- ProgISP

## Custom Delay Library
- delay.c
- delay.h

## Result
LED Blink and Push Button ON/OFF
successfully tested on AT89S52.
